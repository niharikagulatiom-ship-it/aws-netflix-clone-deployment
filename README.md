# Netflix Clone Deployment on AWS using EC2, VPC, Auto Scaling and Load Balancer

In this project, I deployed a Netflix Clone website on AWS using cloud infrastructure and networking services.

**What I implemented:**
- Created a custom VPC with subnets, route tables and an Internet Gateway.
- Launched an EC2 instance and connected to it securely using SSH from Windows CMD.
- Configured the Linux environment and installed the required packages.
- Created an Amazon Machine Image (AMI) from the configured EC2 instance.
- Created a Launch Template to define EC2 instance configurations.
- Configured an Auto Scaling Group to manage EC2 instances.
- Created a Target Group and Application Load Balancer to distribute incoming website traffic.
- Configured Route 53 Hosted Zones and explored domain configuration using Hostinger.
- Deployed and tested the Netflix Clone website through a web browser.

**Technologies Used:** AWS EC2, VPC, Subnets, Internet Gateway, Route Tables, AMI, Launch Template, Auto Scaling, Application Load Balancer, Target Groups, Route 53, Linux, SSH and Hostinger.

**Outcome:** Gained practical hands-on experience in AWS infrastructure setup, Linux administration, cloud networking, website deployment, load balancing and auto scaling.
